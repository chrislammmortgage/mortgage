Connect the services

1. PhoneBurner action needed

  1. You've already generated the Personal Access Token.
  2. Add the token to Vercel: Vercel project → Settings → Environment Variables → add PHONEBURNER_ACCESS_TOKEN = your token. Save, then click "Redeploy" on the latest deployment.
  3. Whitelist the egress. When I just tried the token from outside, PhoneBurner returned "Host not in allowlist" — your account restricts which IPs may hit the API. In PhoneBurner My Account / Integrations, either turn off the API IP allowlist or add Vercel's IP range. The simplest: turn it off (the Bearer token is still the secret).
  4. Webhooks (three URLs to paste): Settings → Integrations → Webhooks → fill the three fields:
    • Call End → /api/webhooks/phoneburner/call-end  (the important one — disposition, transcript, recording)
    • Call Begin → /api/webhooks/phoneburner/call-begin
    • Contact Displayed → /api/webhooks/phoneburner/contact-displayed
    Click "Save Changes" at the bottom.
  5. After all that, hit /api/diagnostics/pb — it should return your member identity and folder list.

2. Salesforce Connected App action needed

  1. SF Setup → App Manager → New Connected App.
  2. Enable OAuth Settings. Callback URL: /api/oauth/salesforce/callback on this host.
  3. Selected OAuth Scopes: api, refresh_token & offline_access.
  4. Save. Wait ~10 minutes for the app to be created.
  5. Capture Consumer Key + Consumer Secret. Paste into Vercel env: SF_CLIENT_ID + SF_CLIENT_SECRET. Redeploy.
  6. Click Authorize Salesforce →. The callback page shows you a refresh token; paste that into Vercel as SF_REFRESH_TOKEN + SF_INSTANCE_URL, redeploy one more time.
  7. Verify with /api/diagnostics/sf — should return your real user identity + a live Contact query.
